# V1.1 資料來源與輸入指紋

## 來源

| 角色 | 資料 | 用途 |
|---|---|---|
| 臺灣市場入口 | 104 各系前十職務 | 提供職稱、在地技能與工具訊號 |
| 職業證據 | O*NET 29.3 | SOC、Job Zone、Skills、Knowledge、Tasks、Technology Skills、Tools |
| 教育—職業探索 | CIP 2020–SOC crosswalk | 補充 104 前十未涵蓋的候選職業方向 |
| 課程候選 | 北科課程主檔 | 課名、描述、開課系所與歷年開課 |
| 修課結構 | 全校課程關聯底圖 | 課程概念去重、正式與建議先備、115 位置與最近開課位置 |

`v1_1_input_manifest.json` 保存本次基準的重要輸入 SHA-256。雜湊用於辨識是否仍是同一份資料，不代表來源本身已完成人工校正。

原始 O*NET、104、CIP–SOC 與校務資料未放入公開靜態網站。重新執行分析時必須由合法取得的本機資料提供，不能只靠本倉庫重建全部結果。

- 入學課程規則：優先採 115。
