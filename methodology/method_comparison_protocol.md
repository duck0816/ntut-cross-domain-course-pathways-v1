# 四版本方法對照實驗規格

四個版本形成「系別固定先驗有／無」與「關鍵字／語意混合檢索」的 2×2 對照。

| 版本 | 系別固定先驗 | 課程檢索 |
|---|---|---|
| A | 有 | V1.1 關鍵字規則 |
| B | 有 | 語意向量＋關鍵字 |
| C | 無 | O*NET 證據衍生關鍵字 |
| D | 無 | O*NET 證據＋語意向量＋關鍵字 |

實驗固定相同職業入口、SOC、O*NET 版本、課程池、開課範圍、限修規則與先備底圖。主要比較單位是未合併的原始職業入口。104 與 CIP–SOC 分開報告，待審映射另做排除後敏感度分析。

無固定先驗版本仍保留職業入口與 CIP 研究範圍，但不得讀取系別能力分類、固定本科底座、職稱增補能力或系別課程關鍵字。其易懂中文名稱只作事後顯示，不得回頭影響分數。

語意版本使用固定的多語模型、共同權重與門檻。調參只使用開發集，保留驗證集在凍結參數前不可查看。AI 代理標記只屬探索性評估，不得標示成人工金標準。
