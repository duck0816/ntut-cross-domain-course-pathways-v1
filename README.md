# 全校科系跨域路徑 V1.1

這是北科大 19 個大學部系所的候選跨域課程路徑靜態成果。每個系所保留職涯路徑、能力與課程證據、八學期時間軸及捷運圖；所有內容均可離線開啟。

- [開啟成果首頁](./index.html)
- 來源分析：`department_pathway_scan_v1_1`
- 資料版本：O*NET 29.3、104 各系前十職務、CIP 2020–SOC、北科課程與 115 課程規則
